# System Monitor

A simple Linux system monitor project to learn and practice multiple programming languages, backend development, and frontend development.

## Back-end

- **Python** - Programming language
  - Flask - Web framework for building a REST API
- **JavaScript** - Programming language
  - Node.js - Runtime for running JavaScript outside the browser
  - Express.js - Web framework for building a REST API
- **Go** - Programming language
  - net/http - Standard library for building an HTTP server and REST API

All three backends will aim to expose the same API endpoints and return data in the same JSON format.

## Front-end

- **HTML** - Page structure
- **CSS** - Styling and layout
- **JavaScript** - Frontend logic and API requests
- **React** - JavaScript library for building a component-based UI (later version)

## System Information

- Linux /proc filesystem - Read system information such as CPU usage, memory, and uptime
- JSON - Data format for communication between the backend and frontend
